This page lists and introduces the blogs we have published on the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

### [Blog 1 - Centralized Amazon Bedrock Access Management and Control with AWS AI Gateway Pattern](3.1-Blog1/)
When deploying Generative AI in an enterprise, Governance is always a major challenge regarding authorization, cost control, and rate-limiting. The AI Gateway architecture solves this by centrally managing all access to Amazon Bedrock through a combination of familiar Serverless services.

### [Blog 2 - Automated 2D Image to 3D Game Asset Conversion using Open-Source Models on AWS EC2](3.2-Blog2/)
Generating 3D assets from 2D images is often time-consuming when done manually. This post shares a workflow for deploying open-source models (TripoSG and MV-Adapter) directly on Amazon EC2 GPU instances to automate 3D model creation, helping game studios easily build Sandbox environments for testing.

### [Blog 3 - Experiencing and Deploying the MiniMax Open-Weight Model Family on Amazon Bedrock](3.3-Blog3/)
MiniMax M2.5 is a specialized Open-weight model family for Agentic Coding and Tool-calling. Discover how to deploy these models on Amazon Bedrock as Fully Managed services, optimizing costs with MoE architecture without the need to manage GPU infrastructure or worry about data security.
